AETL WEBSITE STARTER
======================
This is a static, mobile-friendly website for:
AETL — Advocacy for Ethical & Transformative Leadership

Files:
- index.html — homepage
- about.html — about AETL
- opinion-papers.html — publication archive
- paper-001.html — first publication page placeholder
- author.html — author profile
- contact.html — contact page
- style.css — design

Before publishing:
1. Replace the placeholder title/text on paper-001.html with the approved first opinion paper.
2. Add the public contact email you want displayed.
3. Add a professional headshot and logo if desired.
4. Choose and register an available domain name.
5. Upload the files to a static hosting service.

Suggested domain style:
aetl.org
aetl.ng
aetlleadership.org
aetlopinion.org

Important: do not claim ISSN, DOI, indexing, peer review, or journal status unless those have actually been obtained.
